    怎么导出账单
    1. 支付宝：我的 → 账单 → 右上角「…」→ 开具交易流水证明 → 用于个人对账，选好时间范围，填邮箱。
    2. 微信：我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账，填邮箱。
    3. 邮箱收到的是加密压缩包，先解压（密码在支付宝消息或「微信支付」公众号里），再选里面的 .csv 或 .xlsx 文件。
